Ope is a minimal, cross-platform [Apes.io](https://apes.io/test) client for Windows, macOS, and Linux, designed for stable performance.

# Installation

## Windows

1. Go to the [Releases](https://github.com/pseudoical/ope-client/releases) page.
2. Download the `.msi` file.
3. Run the installer.
4. Launch the application.

## macOS

1. Go to the [Releases](https://github.com/pseudoical/ope-client/releases) page.
2. Download the `.zip` file.
2. Extract the archive.
4. Launch the application.

## Linux

1. Go to the [Releases](https://github.com/pseudoical/ope-client/releases) page.
2. Download the `.AppImage` file.
4. Right-click the application:
   1. Select `Properties`.
   2. Open the `Permissions` tab.
   3. Enable "Allow this file to run as a program".
4. Launch the application.
